compiled the historical and new Git sources using solc 0.8.24, optimizer 200,
and compared the results with live `eth_getCode`:

- Full deployed bytecode matches contract source commit
  `587ceb054d35dd4b7c04a8dd580dcab3b743b30b`, including metadata.
- Full newly compiled bytecode does **not** match the deployment. Both have
  1,397 bytes, but their trailing 53-byte CBOR metadata/length region differs.
- After removing each length-delimited metadata trailer, the 1,344-byte
  executable runtimes are identical. Runtime Keccak:
  `0x6fcce1f70d73a84f5856dd7464f34d26d99f500726e8c653c21dae67b646bb90`.
- ABI and storage layout are also identical. This was not a redeployment or
  explorer source verification. Historical exact-match observations above
  remain valid for the source revision they tested, not arbitrary future main.
